# Real-TV-Time-Simulator 📺

This project aims to create a dynamic real-time web application inspired by TV Time, designed to monitor screen time and simulate live broadcasting engagement. It enables users to organize their media consumption while tracking concurrent live viewers across individual movies and TV series in real time.

- **Application URL:** [https://real-tv-time-simulator.onrender.com/](https://real-tv-time-simulator.onrender.com/)

---

## 🛠️ Stack Tecnologico

L'applicazione è realizzata seguendo i principi dello stack tecnologico **MERN** con architettura containerizzata:

- **MongoDB:** Database NoSQL impiegato per memorizzare il catalogo multimediale, i palinsesti e i dati di tracciamento degli utenti.
- **Express.js:** Framework web flessibile per Node.js utilizzato per implementare le API RESTful e coordinare la logica di backend.
- **React.js (Vite) + Tailwind CSS:** Setup frontend moderno e reattivo per un'interfaccia utente scattante, mobile-ready e orientata alla fruizione in tempo reale.
- **Node.js:** Ambiente di runtime JavaScript per l'esecuzione del server e la sincronizzazione degli stati distribuiti.
- **Docker & Docker Compose:** Containerizzazione completa dei servizi per garantire isolamento, scalabilità e consistenza tra ambienti locali e di produzione.

---

## ✨ Key Features

- **🔴 Interazione Real-Time & Live Viewers:** Monitoraggio dinamico e conteggio in tempo reale degli utenti sintonizzati contemporaneamente sulla stessa scheda di un film o di una serie TV.
- **🎬 Gestione Palinsesto & Watchlist:** Salvataggio dei contenuti preferiti, organizzazione delle serie in corso e avanzamento per episodio e stagione.
- **🔍 Ricerca & Catalogo Dinamico:** Esplorazione rapida di titoli, cast, sinossi e date di uscita con filtri interattivi.
- **🔐 Autenticazione & Stato Distribuito:** Gestione sicura degli accessi utente, sincronizzazione delle preferenze personali e persistenza dei dati.
- **🐳 Architettura a Microservizi Containerizzata:** Configurazione modulare multi-container gestita tramite Docker Compose per facilitare manutenzione, deployment e portabilità.
